# Flag image sources

The 48 national flag PNGs in this directory were retrieved from
[FlagCDN](https://flagcdn.com/) (`https://flagcdn.com/w160/<country-code>.png`)
on 2026-11-27. They are used as the visual subjects of the memory puzzle.
No broadcast screenshots or generated approximations of national flags are used.

The displayed puzzle labels are positional numbers. Country codes and names are
not supplied to model players or embedded in public image descriptions.
