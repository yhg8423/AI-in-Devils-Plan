# 기여하기

방송 규칙을 정리하거나 시뮬레이션에서 발견한 문제를 제보할 수 있습니다. 새 매치를 구현하거나, AI 에이전트의 플레이를 비교할 실험을 제안하거나, 웹과 문서를 개선하는 일에도 참여할 수 있습니다.

## 규칙이나 오류 제보하기

빠진 규칙이나 방송과 다르게 적용된 규칙을 발견했거나, 시뮬레이션 또는 웹에서 오류가 발생했다면 알려 주세요.

- **규칙 제보**에는 방송 회차와 해당 장면의 시각, 빠졌거나 다르게 적용된 규칙을 적어 주세요.
- **오류 제보**에는 문제가 생긴 상황과 나타난 증상을 적어 주세요. 재생 중에 문제가 생겼다면 페이지 주소와 기록 번호를 함께 보내 주세요. 화면 캡처나 사용한 기기·브라우저 정보가 있으면 확인에 도움이 됩니다.

## 기능이나 실험 제안 또는 직접 해보기

웹에서 추가하고 싶은 기능이 있다면 어떤 장면에서 필요했는지, 어떤 기록을 더 쉽게 찾거나 비교하고 싶은지 알려 주세요. 직접 만들어 봤다면 바뀐 화면이나 동작을 공유해 주세요.

시뮬레이션에서는 같은 매치를 실행하면서 모델, 참가자 성향, 정보 공개 범위 같은 조건을 바꿔 볼 수 있습니다. 실험을 제안할 때는 바꿀 조건과 비교하고 싶은 행동이나 결과를 적어 주세요.

직접 [시뮬레이션을 실행했다면](https://github.com/yhg8423/AI-in-Devils-Plan#로컬에서-시작하기) 결과가 담긴 `events.jsonl` 파일을 ZIP으로 압축해 GitHub 이슈에 첨부해 주세요. 사용한 설정과 관찰한 차이도 함께 적어 주세요.

## 코드·테스트·문서에 기여하기

- **매치 구현과 테스트**는 `games/`에서 작업합니다. 새 매치의 규칙, 참가자가 볼 수 있는 정보와 낼 수 있는 행동, 결과 판정을 구현할 수 있습니다. 이미 구현한 규칙을 보완하거나 동점 처리, 비공개 정보 전달, 다음 매치로 넘어가는 조건을 검증하는 테스트도 추가할 수 있습니다.
- **웹 화면과 재생 기능**은 `web/ui/`에서 수정합니다. 모바일 화면, 키보드 조작, 플레이 기록 표시를 개선할 수 있습니다.
- **문서와 페이지 본문**은 한영 README와 `web/ui/content/`에서 수정합니다. 실행 명령이나 게임 규칙 설명을 보완하거나 소개·방법·기여하기 페이지의 문구를 다듬을 수 있습니다.

관련 이슈가 있는지 먼저 확인하고, 규칙 해석이나 기능 범위를 논의할 필요가 있다면 이슈에 의견을 남겨 주세요. [기여 가이드](https://github.com/yhg8423/AI-in-Devils-Plan/blob/main/CONTRIBUTING.md)에 따라 GitHub에서 저장소를 포크하고, 포크를 로컬에 복제한 뒤 작업 브랜치를 만드세요. 수정하고 확인한 내용을 포크의 브랜치에 푸시한 뒤 원본 저장소의 `main`으로 [풀 리퀘스트(PR)](https://github.com/yhg8423/AI-in-Devils-Plan/pulls)를 보내 주세요.

PR에는 변경 내용과 확인 방법을 적어 주세요. 매치 규칙을 구현하거나 바꿨다면 근거가 되는 방송 장면과 검증 결과를, 웹 화면을 바꿨다면 확인한 페이지나 재생 위치를 덧붙여 주세요.
